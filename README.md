# Full Stack Assignments

A collection of Full Stack Development practical assignments covering HTML, CSS, JavaScript, React, Node.js, Express.js, MongoDB, and Git.

## Assignments

| # | Assignment | Description |
|---|-----------|-------------|
| 1 | HTML5 Semantic Tags and CSS3 | A webpage built using HTML5 semantic elements like header, nav, main, article, aside, and footer, styled with CSS3. |
| 2 | HTML5 Navbar, Tables, Forms and CSS3 | A multi-section webpage using Bootstrap with a responsive navbar, cards, and a contact form. |
| 3 | Student Result Management System | A vanilla JS web app that accepts student marks, calculates totals and percentages, and identifies the topper. |
| 4 | Employee Registration Form | A responsive HTML form with client-side JavaScript validation for name, email, password, phone, and department. |
| 5 | Git and GitHub | Demonstrates local Git repository setup, connecting to GitHub, and common Git commands used in this project. |
| 6 | React Student Information Application | A simple React app using two components (StudentForm, StudentDetails) connected with props and useState. |
| 7 | React Personal Expense Tracker | A React app to add and track personal expenses, displaying a running total using useState and array methods. |
| 8 | Node.js, Express.js and MongoDB CRUD API | A backend REST API with full CRUD operations on a Student collection using Express and Mongoose. |
