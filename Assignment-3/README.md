# Assignment 3 – Student Result Management System

## Description
A simple web page that accepts student details and marks, calculates the total and percentage, and displays all student records in a table. It also highlights the topper automatically.

## Files
- `index.html` – Page structure and form
- `style.css` – Basic styling
- `script.js` – Logic for adding results, calculating totals, and finding the topper

## How to Run
Open `index.html` directly in any browser. No server or installation required.

## Features
- Enter student name, roll number, and marks for 3 subjects (each out of 100)
- Click **Add Result** to add the student to the table
- Automatically calculates Total and Percentage
- Displays the current topper above the table
